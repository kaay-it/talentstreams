== Задачи на доработку

=== 🔴 Критично — ключевой пользовательский сценарий

==== TASK-01: Кнопка «Хочу связаться» на странице подборки

*Что сейчас:* кандидаты на `/list/[listId]` — это ссылки на полный профиль (имя, контакты, все данные).

*По ТЗ (§10–12):* каждый кандидат показывается как анонимное Summary с кнопкой «Хочу связаться» под ним. Переход к полному профилю из списка подборки не предусмотрен.

*Что нужно сделать:*

* Убрать переход к полному профилю со страницы подборки.
* Добавить кнопку «Хочу связаться» под каждой карточкой.
* При нажатии — сохранить запрос: компания работодателя, ID кандидата, стрим, дата и время.
* Уведомить администратора (email).

*Затрагивает:* `app/list/[listId]/page.tsx`, `app/actions.ts`, `lib/sheets.ts`.

---

==== TASK-02: Система отслеживания запросов «Хочу связаться»

*Что сейчас:* отсутствует полностью.

*По ТЗ (§12):* при нажатии «Хочу связаться» создаётся запрос с жизненным циклом и набором статусов.

*Статусы запроса:*

. Новый запрос
. Кандидату написали
. Кандидат не отвечает
. Связаться с Аленой
. Кандидату интересно
. Кандидату не интересно
. Контакты переданы

*Поля запроса:*

* Компания (работодатель)
* Контактное лицо работодателя
* ID кандидата
* Talent Stream
* Дата и время запроса
* Текущий статус

*Что нужно сделать:*

* Создать лист «Contact Requests» в Google Sheets.
* Добавить `appendContactRequest()` в `lib/sheets.ts`.
* Добавить страницу просмотра/управления запросами в `/editor` или отдельным маршрутом.
* Реализовать смену статуса запроса (Server Action).

=== 🟠 Важно — бизнес-правила

==== TASK-05: Правила публикации кандидатов

*Что сейчас:* нет отслеживания дат публикации, нет защиты от нарушения правил.

*По ТЗ (§13):*

* Первая публикация → фиксируется дата.
* Через 2 недели возможна повторная публикация.
* После второй публикации — пауза 3 месяца.
* Кандидат может попросить статус «Не публиковать».

*Что нужно сделать:*

* Добавить в карточку кандидата (Google Sheets): дата первой публикации, дата последней публикации, статус (Активный / На паузе до даты / Не публиковать).
* В редакторе при выборе кандидатов для выпуска: показывать статус публикации и дату, с которой публикация снова разрешена.
* Предупреждение, если кандидат добавлен в подборку, но находится в паузе.

==== TASK-09: Процесс подтверждения регистрации работодателя

*Что сейчас:* форма сразу записывает работодателя в Sheets и добавляет в SendPulse — без промежуточного шага проверки.

*По ТЗ (§14):* заявка → администратор проверяет → подтверждает → только после этого работодатель получает доступ и приветственное письмо.

*Что нужно сделать:*

* Добавить колонку «Статус» в лист Employers (На проверке / Подтверждён / Отклонён).
* При регистрации: сохранять со статусом «На проверке», *не добавлять в SendPulse*.
* В редакторе: список заявок работодателей на проверке, кнопка «Подтвердить».
* При подтверждении: добавить в SendPulse, отправить приветственное письмо (TASK-10).
